# 코드 생성 규칙
- 입문 개발자를 고려하여 모든 코드는 상세한 주석을 달아준다.
- 코드는 입문자 수준의 간단한 코드를 위주로 작성한다. 
  
## 1. 프로젝트 목표
- 입문자를 위한 풀스택 학습용
- 풀스택 전체 과정을 하드코딩하면서 기술스택을 이해한다.
- 풀스택 전체를 직접 완성함으로서 성취감을 갖도록 한다.
- 복잡한 로직이 중요한 것이 아니고 풀스택 구조를 이해하고 이를 직접 구현함으로서 풀스택의 구성요소를 이해한다.
## 2. 프로젝트 제목
- 웹용 음료수 자판기(간단한 쇼핑몰)

## 3. 프로젝트 요구사항
- 미니 쇼핑몰과 같은 서비스를 제공한다.
- 관리자가 상품, 판매, 재고 기능을 관리할 수 있다.
- 관리자가 회원관리를 한다.
- 사용자는 회원가입하고 서비스를 제공 받는다.
